# Material para estudiar Hundir la Flota

1. Empieza por [GUIA_ESTUDIO_Y_EXPOSICION.md](GUIA_ESTUDIO_Y_EXPOSICION.md).
2. El código original copiado está en `codigo/`: `variables.py`, `clases.py`, `funciones.py`, `main.py`, `lanzar_presentacion.py` y `presentacion.html`.
3. Para jugar en consola: abre una terminal en `codigo/` y ejecuta `python3 main.py`.
4. Para mostrar la web: ejecuta `python3 lanzar_presentacion.py`.

La guía incluye el código real completo de cada archivo, explicaciones por líneas y por bloques, conceptos clave, un guion de diez minutos, pasos para una demo y preguntas posibles.
